⛪ Gestor Financiero Ministerial Pro v74.0

Sistema integral de gestión contable diseñado para ministerios e iglesias, enfocado en la transparencia, el orden y la seguridad de los recursos. Esta aplicación permite llevar un control detallado de ingresos, gastos y ahorros por proyectos específicos con respaldo automático en la nube.

🚀 Características Principales

Bóveda Inteligente: Visualización en tiempo real del saldo total y capacidad de gasto seguro (protegiendo el fondo de reserva).

Gestión por Proyectos: Registra ingresos y egresos asignados a metas específicas (ej. Convención, Instrumentos, Ayuda Social) con barras de progreso.

Libros Auxiliares Detallados: Navegación "Drill-down" para ver el historial cronológico exacto de cada fondo o proyecto de forma independiente.

Sincronización Cloud: Sistema de identidad ministerial mediante correo electrónico para persistencia de datos en Firebase Firestore.

Reportes de Alta Fidelidad: Generación automática de Estado de Situación Financiera y Estado de Resultados (Flujo de Caja) listos para auditoría.

PWA (Progressive Web App): Tecnología que permite instalar la herramienta en dispositivos móviles como una aplicación nativa, con icono propio y funcionamiento a pantalla completa.

🛠️ Tecnologías Utilizadas

React.js: Para una interfaz de usuario reactiva, fluida y de alto rendimiento.

Tailwind CSS: Diseño moderno, limpio y optimizado para dispositivos móviles ("Mobile-First").

Firebase (Firestore & Auth): Base de datos NoSQL en tiempo real y autenticación de seguridad.

Lucide React: Iconografía profesional y minimalista.

📥 Instalación (Pasos para lanzarlo como App Real)

Para que el sistema funcione con todas sus capacidades de nube y sea instalable, sigue estos pasos:

GitHub: Crea un repositorio llamado tesoreria-juvenil y sube el archivo App.jsx junto a este README.md.

Despliegue: Conecta tu repositorio con Vercel o Netlify. Asegúrate de configurar las variables de entorno si es necesario (aunque el código actual incluye la configuración base).

En el Celular:

Abre la URL generada por Vercel (ej. https://tu-iglesia.vercel.app).

iOS (Safari): Toca "Compartir" y selecciona "Añadir a pantalla de inicio".

Android (Chrome): Toca los tres puntos y selecciona "Instalar aplicación".

📊 Guía de Operación

Configuración Inicial: Pulsa el icono de engranaje (arriba a la derecha) para registrar el nombre de tu iglesia y tu correo de respaldo.

Registros: Usa los botones Ingreso o Gasto. Si el dinero pertenece a una meta de ahorro, activa el botón "¿Asignar a un Proyecto?".

Auditoría: En la pestaña Reporte, podrás ver el balance consolidado y enviarlo directamente por WhatsApp al liderazgo de la iglesia.

Este proyecto busca la excelencia en la mayordomía de los recursos del Reino.
